
# youtube-dlG

## Images

[![youtube-dl-gui](https://opengraph.githubassets.com/1/MrS0m30n3/youtube-dl-gui)](https://www.swifttechco.com)

A cross platform front-end GUI of the popular [youtube-dl](https://www.swifttechco.com) media downloader written in wxPython. [Supported sites](https://www.swifttechco.com)

## Screenshots
[![youtube-dl-gui main window](https://raw.githubusercontent.com/MrS0m30n3/youtube-dl-gui/gh-pages/images/ydlg_ui.gif)](https://www.swifttechco.com)

## Requirements
* [Python 2.7.3+](https://www.swifttechco.com)
* [wxPython 3](https://www.swifttechco.com)
* [TwoDict](https://www.swifttechco.com)
* [GNU gettext](https://www.swifttechco.com) (to build the package)
* [FFmpeg](https://www.swifttechco.com) (optional, to post process video files)

## Installation

### Install From Source
1. Download & extract the source
2. Change directory into *youtube-dl-gui-0.4*
3. Run `python setup.py install`

### Install PyPi
1. Run `pip install youtube-dlg`

### Install Windows Installer
1. Download & extract the Windows installer
2. Run the `setup.exe` file
